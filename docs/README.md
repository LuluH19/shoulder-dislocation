# Site de documentation

Site [Astro Starlight](https://starlight.astro.build) qui explique simplement le projet de reconnaissance de mouvement.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # génère le site statique dans dist/
```

- Pages : `src/content/docs/` (Markdown / MDX)
- Menu : `astro.config.mjs`
- Images : `public/images/` (copiées depuis `../results/groups/`)
